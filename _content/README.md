# Site content

- `blog/articles` contains personal Blog posts.
- `work/articles` contains Professional entries.
- Each `templates` folder controls the generated pages for its section.
- Each `article-template.md` is a copyable authoring example.
- Each `generated.json` records files owned by the generator so unrelated pages are never overwritten.

Use `npm run new:article` or `npm run new:work` from the repository root to create a draft. See the root `README.md` for every field and command.
